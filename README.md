# SMCI — Reservation-Backed AI Factory

Static, GitHub Pages–ready academic website. Required independent pages: Introduction, Proposed Business Model, References. Includes all 18 provided Power BI image exports.

## Publish
1. Create a **public** GitHub repository, for example `smci-business-model`.
2. Upload the contents of this folder into the **root** of the new repository (not the enclosing folder).
3. In repository **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**; save.
4. The site appears at `https://YOURUSERNAME.github.io/smci-business-model/`.

## Caveats
- Company/product photos are linked from third-party/official web image URLs and require internet access. The 18 charts are packaged locally.
- Power BI workspace and original `.pbix` must be supplied separately; exported images do not grant report access.
- Statements and model numbers are reproduced from the uploaded source document; they have not been independently audited.
